# 夜波 NIGHTWAVE

一个虚构的上海深夜电台单页网站，用纯 HTML、CSS 和原生 JavaScript 完成。视觉方向结合了编辑设计、印刷排版与午夜广播：米色纸张、油墨黑、信号橙、黑胶唱片、旋转唱臂和带颗粒感的背景。

> 这是一个前端演示项目。电台、节目、主持人、频率、邮箱与社交账号均为虚构。

## 本地预览

项目没有构建步骤，也不需要安装依赖。推荐用本地静态服务器打开：

```bash
cd /projects
python3 -m http.server 4173
```

然后访问 <http://localhost:4173>。

也可以直接双击 `index.html`，但使用本地服务器能获得更一致的字体与资源加载表现。

## 功能与交互

- **响应式单页布局**：覆盖宽屏、笔记本、平板、手机到 320px 窄屏，导航在移动端折叠为菜单。
- **节目联动**：点击「今晚节目」中的任意节目，会同步更新首屏正在播出信息、节目单中的 ON AIR 标记、播放器和底部播放条。
- **声音档案**：三张编辑式错位卡片，展示过往节目与照片。
- **可播放的电台环境声**：点击唱片、播放按钮或底部播放条，使用 Web Audio API 实时合成不同节目的环境音；再次点击暂停。
- **实时细节**：页头显示上海时间、滚动进度、滚动显现动画、旋转黑胶与唱臂。
- **订阅表单**：包含邮箱格式校验、错误提示与成功反馈。
- **无障碍**：语义化结构、跳转到主内容的链接、键盘焦点样式、ARIA 状态、`aria-live` 提示，以及 `prefers-reduced-motion` 降级。

## 技术说明

- 无框架、无构建工具、无 JavaScript 依赖。
- 声音不是音频文件，而是由振荡器、噪声层、滤波器与压缩器实时生成；浏览器要求用户手势后才能启动音频。
- 字体通过 Google Fonts 加载：Instrument Serif、Noto Serif SC、Noto Sans SC 和 IBM Plex Mono；断网时会回退到本地字体栈。
- 图片存放在 `assets/`，使用本地相对路径；照片仅作为演示素材。
- 主要颜色、字体与节奏变量集中在 `styles.css` 顶部的 `:root`；节目数据与合成器参数集中在 `script.js` 的 `SHOWS` 对象中。

## 浏览器支持

建议使用较新版本的 Chrome、Edge、Firefox 或 Safari。缺少 Web Audio 支持时，页面其余内容与交互仍可正常使用。
